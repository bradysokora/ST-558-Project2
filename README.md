# Melbourne Housing Explorer (ST 558 Project 2)

This is a Shiny app for exploring property sales in Melbourne, Australia. You can filter the data from the sidebar by property type, region, and a couple of numeric variables, then look at the filtered data, download it, or make tables and plots from it.

## Data

Melbourne Housing Snapshot from Kaggle: https://www.kaggle.com/datasets/dansbecker/melbourne-housing-snapshot

## Files

- `app.R` is the Shiny app
- `helpers.R` has the shared cleaning function, variable lookups, and summary helpers
- `eda.qmd` is the static exploration I did before building the app
- `data/` holds the csv
- `www/` holds the image used on the About tab
